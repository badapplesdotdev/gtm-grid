A redesigned update experience: the update dialog now shows what's actually in the release (new features vs fixes, with version chips), a live download progress bar, and clear verify/restart steps — downloads start when you choose, not silently. After updating, a "What's new" welcome recaps the release, and a new full Changelog (⌘K → "What's new / Changelog") shows every release on a version timeline.
